## 1. QueuePage — Contraste modo claro

### Problema

A página da Fila usa `bg-bg-primary` (branco em light mode) para:

- Cards de fases inactivas do pipeline: `border-border bg-bg-primary` → borda `#e2e8f0` quase invisível sobre fundo branco
- Contentor do ícone Film nos jobs em processamento: `w-12 h-12 bg-bg-primary rounded-lg` → quadrado branco sobre card branco

Em modo escuro funciona correctamente porque `bg-bg-primary = #0a0d14` (escuro).

### Ficheiro afectado

`src/pages/QueuePage.tsx`

### Solução

**Cards de fases inactivas** (bloco do pipeline em processamento, linha ~358):

```tsx
// ANTES:
: 'border-border bg-bg-primary'
// DEPOIS:
: 'border-border bg-bg-tertiary dark:bg-bg-primary'
```

**Contentor do ícone Film** (linha ~315):

```tsx
// ANTES:
<div className="w-12 h-12 bg-bg-primary rounded-lg flex items-center justify-center">
// DEPOIS:
<div className="w-12 h-12 bg-bg-tertiary dark:bg-bg-primary rounded-lg flex items-center justify-center">
```

`bg-bg-tertiary` = `#f1f5f9` em light mode (cinzento ligeiro, visível) = `#0f121a` em dark mode (quase igual ao `bg-bg-primary` escuro — imperceptível).

## 4. Histórico de Jobs — Pipeline horizontal com progressão em tempo real

### Problema

No tab "Histórico de Processamento" de `AssetDetailPage`, o mini-pipeline mostra todos os steps como done/not-done (binário). Para jobs em processamento (`status === 'processing'`), o utilizador não consegue ver qual a fase activa nem o progresso percentual.

### Abordagem escolhida

**Fases agrupadas compactas** (estilo QueuePage mas menor), usando dados já disponíveis: `job.step` (step activo) e `job.progress` (0-1 float).

### Dados necessários

- `PIPELINE_PHASES` e `PIPELINE_STEPS` — constantes definidas em `QueuePage.tsx`. Extrair para `src/lib/pipeline.ts` para partilha entre QueuePage e AssetDetailPage.
- `job.step: string | null` — já presente no tipo `Job`
- `job.progress: number` — já presente no tipo `Job`

### Ficheiros afectados

- `src/lib/pipeline.ts` (novo — extrair constantes)
- `src/pages/QueuePage.tsx` (importar de pipeline.ts em vez de definir localmente)
- `src/pages/AssetDetailPage.tsx` (usar nova UI para jobs em processamento)

### Solução

**Extrair para `src/lib/pipeline.ts`:**

```typescript
export const PIPELINE_STEPS = [
  { key: 'ingest', short: 'IN' },
  { key: 'qc_pre', short: 'QP' },
  { key: 'transcode', short: 'TR' },
  { key: 'audio', short: 'AU' },
  { key: 'thumbnail', short: 'TH' },
  { key: 'qc_post', short: 'QP2' },
  { key: 'delivery', short: 'DE' },
] as const;

export const PIPELINE_PHASES = [
  { labelKey: 'pipeline.phase.ingest', steps: ['ingest', 'qc_pre'] },
  { labelKey: 'pipeline.phase.process', steps: ['transcode', 'audio', 'thumbnail'] },
  { labelKey: 'pipeline.phase.deliver', steps: ['qc_post', 'delivery'] },
] as const;

export function getStepIndex(stepKey: string | null): number {
  if (!stepKey) return -1;
  return PIPELINE_STEPS.findIndex((s) => s.key === stepKey);
}
```

**Nova UI no histórico de jobs — para `job.status === 'processing'`:**

Substituir o bloco `{/* MINI PIPELINE */}` (linhas ~930-959 em AssetDetailPage) pela lógica de fases:

```tsx
{
  job.status === 'processing' && (
    <>
      {/* FASES COMPACTAS */}
      <div className="flex items-stretch gap-2 mb-4">
        {PIPELINE_PHASES.map((phase, phaseIdx) => {
          const stepIndices = phase.steps.map((s) => getStepIndex(s));
          const phaseMin = Math.min(...stepIndices);
          const phaseMax = Math.max(...stepIndices);
          const currentIdx = getStepIndex(job.step);
          const isDone = currentIdx > phaseMax;
          const isActive = currentIdx >= phaseMin && currentIdx <= phaseMax;
          return (
            <React.Fragment key={phase.labelKey}>
              <div
                className={`flex-1 rounded-xl border p-2 flex flex-col gap-1.5 transition-all ${
                  isDone
                    ? 'border-green-500/40 bg-green-500/5'
                    : isActive
                      ? 'border-brand/60 bg-brand/5'
                      : 'border-border bg-bg-tertiary dark:bg-bg-primary'
                }`}
              >
                <div className="flex items-center gap-1.5">
                  <div
                    className={`w-3 h-3 rounded-full flex-shrink-0 flex items-center justify-center ${
                      isDone ? 'bg-green-500' : isActive ? 'bg-brand' : 'bg-surface'
                    }`}
                  >
                    {isDone && <CheckCircle2 size={8} className="text-white" />}
                    {isActive && (
                      <div className="w-1.5 h-1.5 bg-white rounded-full animate-pulse" />
                    )}
                  </div>
                  <span
                    className={`text-[9px] font-black uppercase tracking-widest ${
                      isDone ? 'text-green-500' : isActive ? 'text-brand' : 'text-text-muted'
                    }`}
                  >
                    {t(phase.labelKey)}
                  </span>
                </div>
                <div className="flex gap-1 flex-wrap">
                  {phase.steps.map((stepKey) => {
                    const idx = getStepIndex(stepKey);
                    const currentIdx = getStepIndex(job.step);
                    const stepDone = idx < currentIdx;
                    const stepActive = idx === currentIdx;
                    return (
                      <span
                        key={stepKey}
                        className={`px-1 py-0.5 rounded text-[8px] font-bold uppercase ${
                          stepDone
                            ? 'bg-green-500/20 text-green-500'
                            : stepActive
                              ? 'bg-brand/20 text-brand'
                              : 'bg-surface text-text-muted'
                        }`}
                      >
                        {t(`pipeline.${stepKey}`)}
                      </span>
                    );
                  })}
                </div>
              </div>
              {phaseIdx < PIPELINE_PHASES.length - 1 && (
                <div className="flex items-center mt-1">
                  <div
                    className={`w-4 h-0.5 ${
                      getStepIndex(job.step) > Math.max(...phase.steps.map(getStepIndex))
                        ? 'bg-green-500'
                        : 'bg-surface'
                    }`}
                  />
                </div>
              )}
            </React.Fragment>
          );
        })}
      </div>

      {/* BARRA DE PROGRESSO DO STEP ACTIVO */}
      <div className="space-y-1">
        <div className="flex justify-between items-center">
          <span className="text-[10px] font-bold text-brand">
            {t(`pipeline.${job.step ?? 'wait'}`, job.step ?? '…')} —{' '}
            {(job.progress * 100).toFixed(0)}%
          </span>
          <span className="text-[10px] text-text-muted">{t('queue.step', { step: job.step })}</span>
        </div>
        <div className="w-full h-1.5 bg-surface rounded-full overflow-hidden">
          <div
            className="h-full bg-brand transition-all duration-500"
            style={{ width: `${(job.progress * 100).toFixed(0)}%` }}
          />
        </div>
      </div>
    </>
  );
}

{
  /* Para jobs concluídos — mini pipeline original melhorado (tudo verde) */
}
{
  job.status !== 'processing' && (
    <div className="flex items-center justify-between mb-6 px-2">
      {PIPELINE_STEPS.map((step, idx) => {
        const isDone = job.status === 'done';
        return (
          <React.Fragment key={step.key}>
            <div className="flex flex-col items-center gap-1">
              <div
                className={`w-5 h-5 rounded-full border flex items-center justify-center ${
                  isDone
                    ? 'bg-green-500 border-green-500 text-white'
                    : 'border-border text-text-muted'
                }`}
              >
                {isDone ? (
                  <CheckCircle2 size={10} />
                ) : (
                  <span className="text-[8px] font-bold">{step.short}</span>
                )}
              </div>
            </div>
            {idx < PIPELINE_STEPS.length - 1 && (
              <div className={`flex-1 h-px mx-[-2px] ${isDone ? 'bg-green-500' : 'bg-border'}`} />
            )}
          </React.Fragment>
        );
      })}
    </div>
  );
}
```

## 5. Versão completa no sidebar

### Problema

O sidebar inferior mostra `v{appVersion}` onde `appVersion` vem de `getVersion()` (API Tauri) que retorna apenas a versão numérica do `tauri.conf.json` (ex: `0.30.9`). O utilizador quer ver a versão completa incluindo sufixo pre-release (ex: `v0.30.9-beta.1`), igual ao que aparece em Definições > Sobre.

### Ficheiro afectado

`src/App.tsx`

### Solução

Importar `APP_VERSION` de `@/lib/version` (já tem `0.30.9-beta.1`) e usar directamente:

```tsx
// Adicionar import no topo:
import { APP_VERSION } from '@/lib/version';

// Substituir no sidebar (linha ~375):
// ANTES:
<span className="text-[10px] font-bold text-brand uppercase">v{appVersion}</span>
// DEPOIS:
<span className="text-[10px] font-bold text-brand">{APP_VERSION}</span>
```

Remover o estado `appVersion`, o `useEffect` do `getVersion()`, e o import de `getVersion` — se não forem usados noutro lado em App.tsx.

**Verificar** se `appVersion` é usado noutro sítio em App.tsx antes de remover o estado.
